# ESP8266 温湿度数据

室内 DHT11 / DHT22 双路温湿度，采样间隔 10 秒，由一块 ESP-12E 直接提交上来，
不依赖任何电脑常开。

## 目录

| 路径 | 内容 |
|---|---|
| `archive/YYYY-MM-DD.csv` | 历史归档（电脑端 SQLite 里的存量数据一次性导出），每行带完整时间 |
| `data/YYYY-MM/YYYY-MM-DD/HHMM.csv` | 单片机直传，每 10 分钟一个文件 |
| `status/heartbeat.csv` | 手动自检时写的探测文件，可忽略 |

## CSV 格式

`archive/*.csv`（5 列）：

```
time,t11,h11,t22,h22
2026-10-03T18:44:36+08:00,22.2,71,43.2,39.2
```

`data/**/HHMM.csv`（5 列，日期由路径给出）：

```
14:30:04,14.4,73,14.4,84.6
```

- `t11/h11` = DHT11，`t22/h22` = DHT22，温度 ℃、湿度 %RH
- 读取失败的字段留空，例如 `14:30:14,,,14.4,84.6`
- 时间统一为东八区（脚本里固定 +08:00）

## 数据说明

- 采样 10 秒一条，10 分钟一个文件、一个 commit
- 网络中断时数据先存在板子的 flash 里（约可存 10 天），恢复后自动补传
- ESP8266 没有 RTC，时间来自 NTP；断网重启后会等 NTP 同步成功才开始记
- 已有的踩坑记录：DHT11 在 14℃ 左右会整段读取失败；DHT11 湿度比 DHT22 系统性低约 12%RH
